# Change log

## 2.0.0 — 2026-09-26 — agent-driven architecture revision

Complete replacement pack derived from 1.0.0. This is a specification revision, not an implemented application release. No original relative paths were removed or renamed. Preserve local edits and measured progress through [MIGRATION.md](MIGRATION.md).

### Principal changes

- Expand the runtime from approved-strategy selection to four logical tool-using roles: analyst, researcher, evaluator and coordinator. Default transport is a finite application-brokered JSON action loop around Codex CLI; native machine tools remain restricted.
- Add registered-source investigations, bounded declarative experiments, isolated shadows, exact-hash reviews, discretionary trading/management intents, durable feedback, revocation and owner-derived authority checks.
- Keep routine actions automatic within an approved policy. New main strategy logic/domains, higher limits and privileged capabilities still need owner approval. A bounded choice inside an already approved domain uses explicit membership proof.
- Add three focused domain contracts and four isolated role-prompt templates, a migration guide and a 38-item capability/control checklist. Update existing architecture, risk/operating contracts, UI, evaluation, task templates and M0–M8 roadmap consistently.
- Preserve the selected frontend/preset/skills, local Docker, paper-only BTC/SOL scope, virtual funding/top-ups, core ledger/fill semantics and numeric hard-risk proposal. Do not interpret greater autonomy as permission for live orders or paid API fallback.
