### 4.4 Failures

- **The model's failures count as starts**, as 0052's: an answer refused (a schema failure, a refusal, a cut answer), a timeout, a spent budget, a finish refused, a failed binding. A step with 3 starts and none open is recorded `UNANSWERED`. A start canceled to make way for a decision is not one.
- **A provider failure is not a start:** a workflow that ended `AUTH_REQUIRED` or `QUOTA_BLOCKED`, or `FAILED` with `RATE_LIMITED`, `PROVIDER_UNAVAILABLE`, `PERMISSION_DENIED`, `REQUEST_REFUSED` or a runner error. It ends its workflow at once, with no retry inside it, so it spends none of the model's steps; a timeout keeps its retry, as the model's failure (§12). The lane then waits, and asks the step again with a new workflow and its whole budget: 2 minutes after one; 1 hour after `QUOTA_BLOCKED` (the credit), `PERMISSION_DENIED` or `REQUEST_REFUSED` (a request the API refuses, so the same next time), and after five provider failures in a row. After `AUTH_REQUIRED` the runner marks the key refused, and the lane waits until the owner saves a new one (`KEY_REFUSED`). The run is never stopped for a provider failure, so nothing is lost while it waits.
- **Isolation:** a call whose adapter is not the profile's neither sets the usage-limit block nor lifts it (`usage.block`, `usage.clear` only for a call of the provider in force), so the live agents on Codex never wait for Claude's credit. The live agents' sign-in state is Codex's alone, as before. A capability violation still moves `ENABLED` to `PROBE_ONLY` until the agents' check passes again, whatever the call (protection, kept).

### 4.5 The money

- **The cap: $120 for the whole run**, under the key's remaining credit. Counted: each Claude-lane call's cost as `spend.cost` prices it from its tokens, and $0.20 for a call with no priced outcome that the API may have billed (in flight, completed or killed without usage, timed out, canceled, outcome unknown, or failed without an HTTP refusal); $0.20 is about the most one call can cost (16,000 output tokens at $10 per million, $0.16, plus about 20,000 input tokens). A call refused with 401, 402, 403, 429 or 400 costs nothing. A workflow starts only while the counted spend is at most $119, so the run stays under $120; once the spend is above that with none open, the run ends `STOPPED` with `SPEND_CAP_REACHED`.
- **What it may cost** (`CALCULATED`, rough): a trader step at about 10,000 to 12,000 input tokens (about 2,000 of them the cached role block) and 700 to 1,900 output tokens with Claude's thinking at `medium` is about $0.03 to $0.04 for one call, more when it reads candles first (a second or third call); about 1,850 workflows: **about $55 to $95, most likely $60 to $90**. A model that reads before most answers could pass $120: the run then ends partial (§4.7).
