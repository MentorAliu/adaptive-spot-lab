# Archive

Frozen history, kept verbatim: finished ExecPlans (0001 to 0059), the command and test run records up to 2026-10-20, the status history, the milestone evidence maps of TESTING, the two Narrator checklists and the pack-2.0.0 files (`START_HERE`, `MANIFEST`, `MIGRATION`, `CHANGELOG`, `PACK_VALIDATION`) that described the app before it was built. Moved here by [ExecPlan 0034](plans/0034-app-cleanup.md) on 2026-10-20; [ExecPlan 0060](../plans/0060-spot-trading-only.md) added the AI's contracts on 2026-11-12, and [ExecPlan 0061](../plans/0061-clean-up-after-the-spot-switch.md) the same day plans 0033 to 0059, the contracts as they stood before the spot app's rewrite, and the agents' ideas and the research templates. Only their relative links were rewritten to the new paths, and heading texts are unchanged so old anchors still work.
- Links into these files are for searching. Agents never read them whole at the start of a task: search (`grep`) for the section you need and read that.
- Nothing here is a current rule. Where an archived file and a current document disagree, the current document wins ([STATUS](../STATUS.md), [the documents index](../README.md)).
- Do not edit these files except to keep their links working. New results go into the active plan.
